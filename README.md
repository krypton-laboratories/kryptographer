# Kryptographer

***Next-Level Security***

## About

Kryptographer is an **adaptive AI versus AI traffic obfuscation** that fights surveillance, profiling, censorship, and data leakage by breaking traffic classifiers. To protect users, Kryptographer evolves and changes itself in response to threat while **preserving privacy to the next level.**

### Our Story

Kryptographer was Krypton Laboratories' submission for the **Cyber-Security and Technology** category of the [Conrad Challenge](https://conrad.spacecenter.org), a global student innovaion competition sponsored by the [Space Center Houston](https://spacecenter.org). This project advanced to the **Innovation Stage**, the semifinal round of the competition. This website serves as a way to pitch our product idea and present our prototype. The final product is currently a **work in a progress.**

## Behind the Website

The Kryptographer website was created with HTML, CSS, and JavaScript. Apart from using jQuery for DOM manipulation, no special libraries or frameworks were utilized in the development process. The only code that was adapted from someone else's work was the background particle animation from [Vincent Garreau's](https://github.com/VincentGarreau) [particles.js](github.com/VincentGarreau/particles.js) repository. The rest of the code and content of this website was written by the members of the [Krypton Laboratories team](https://krypton-laboratories.github.io/kryptographer/about.html).

### Struggles and Lessons

For our [Conrad Challenge](https://conrad.spacecenter.org) submission, we had to write an [Innovation Brief](https://conrad.spacecenter.org/the-challenge/innovation-stage/) answering essential questions about our product idea. When we began the process of developing our website for our submission, we struggled to figure out how to present the information on our Innovation Brief in a digestible form.

After initially trying to convey the entirety of our Innovation Brief in our three-page website, we eventually realized that the most effective way of showcasing our project was to present it as a product pitch. This way, we focused on including only the most important and notable details about our idea in a aesthetically pleasing manner, rather than having abundant walls of text on every page.

## Local Development

### Prerequisites

- A modern web browser

- A code editor

### How to Run

1. Open a terminal

2. Clone this repository with Git:

    ```bash
    git clone https://github.com/krypton-laboratories/kryptographer.git
    cd kryptographer
    ```

3. Open your file explorer

4. Navigate to the `kryptographer` directory

5. Open `index.html` in your browser
